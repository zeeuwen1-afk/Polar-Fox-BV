## Fase 5: Worker (25 september 2026)

| #   | Besluit                                                                                                                                           | Waarom                                                                                                                                                 |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 5.1 | **Eén Worker voor site én API**: `assets.run_worker_first = ["/api/*"]`, al het andere komt uit `../dist`.                                        | Eén deploy, geen aparte domeinen of CORS-gedoe in productie; de site en de API delen dezelfde origin.                                                  |
| 5.2 | **Origin-controle plus CORS-allowlist** (`ALLOWED_ORIGINS`), en een verzoek zonder `Origin` krijgt 403.                                           | Het formulier wordt alleen door de eigen site aangeroepen; scripts zonder Origin zijn per definitie geen browserverzoek van onze pagina.               |
| 5.3 | **Honeypot gevuld = 200 zonder mail.**                                                                                                            | Een bot die "succes" ziet, probeert het niet opnieuw; een 400 zou hem juist informatie geven.                                                          |
| 5.4 | **Rate limiting via KV op de gehashte IP** (sleutel per uurvenster, TTL ruimt op); zonder binding wordt het overgeslagen met een waarschuwing.    | Geen ruwe IP's in KV, hetzelfde hashmechanisme als de logs. Lokaal werkt het zonder KV; in productie is de binding verplicht (zie CHECKLIST-LIVEGANG). |
| 5.5 | **Alleen tekstmails via Brevo** (`textContent`, geen `htmlContent`), regeleinden uit invoer gestript.                                             | Geen tracking-pixel, niets te escapen naar HTML, geen header-injectie via de naam.                                                                     |
| 5.6 | **Melding aan Polar Fox eerst en synchroon; bevestiging aan de aanvrager via `waitUntil`.**                                                       | Als de melding faalt krijgt de bezoeker een 502 en blijft zijn invoer staan; een mislukte bevestiging mag de aanvraag niet blokkeren.                  |
| 5.7 | **Foutantwoorden generiek**, maar met `errors` per veld bij 400 en 403 (Turnstile).                                                               | De wizard toont zo dezelfde meldingen als bij clientvalidatie, zonder interne details te lekken.                                                       |
| 5.8 | **Worker-tests draaien in Node-Vitest** met een KV-map, een Turnstile-fetch-mock en een mailer-mock; `deps` op `handleIntake` maakt dat mogelijk. | Zie besluit 1.5; de handler is puur genoeg om zonder workerd te testen. `npm run check` typechecked de Worker apart met `@cloudflare/workers-types`.   |

## Fase 6: beveiliging en headers (25 september 2026)

| #   | Besluit                                                                                                                            | Waarom                                                                                                                                                                                          |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 6.1 | **CSP gesplitst**: `script-src`/`style-src` met hashes in de meta-tag van Astro, `frame-ancestors` en consorten in de HTTP-header. | Een statische header kan geen per-pagina hashes bevatten en zou de eigen scripts blokkeren; een meta-tag kan geen `frame-ancestors`. Samen dekken ze de hele briefing zonder `'unsafe-inline'`. |
| 6.2 | **Headers op twee plekken**: `public/_headers` én `worker/src/headers.ts` (zet alleen wat ontbreekt).                              | `_headers` is de Cloudflare-standaard; het Worker-vangnet garandeert de headers ook als de assets-laag het bestand niet toepast. Getest in `headers.test.ts`.                                   |
| 6.3 | **`Cross-Origin-Opener-Policy: same-origin` en `Cross-Origin-Resource-Policy: same-origin`, geen `Cross-Origin-Embedder-Policy`.** | COOP/CORP zijn gratis winst; COEP `require-corp` zou het Turnstile-iframe breken.                                                                                                               |
| 6.4 | **Dependabot** wekelijks, gegroepeerd per stack (Astro, React, tooling, tests, Cloudflare) en voor GitHub Actions.                 | Gevraagd in de briefing; groepering houdt het aantal PR's werkbaar.                                                                                                                             |
| 6.5 | **Mozilla Observatory-score** wordt pas na livegang gemeten (staat in CHECKLIST-LIVEGANG en RUNBOOK).                              | Die tool heeft een publiek bereikbare URL nodig; lokaal zijn de headers met curl en Playwright gecontroleerd.                                                                                   |
